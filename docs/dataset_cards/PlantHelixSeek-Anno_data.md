# Gene-annotation benchmark data

This directory contains example input for the `PlantHelixSeek-Anno` pipeline.

13 training species and 7 benchmark species; see Supplemental Tables 5 and 9 and Figure 4.

The full training and benchmark data are distributed through the PlantHelixSeek
collection on Hugging Face (https://huggingface.co/collections/zhangtaolab/planthelixseek)
and ModelScope. The pipeline code is in `scripts/` of this repository.

## Citation

Wu Y, He Y, Chen L, Liu Y, Wang T, Zhao H, Zhang Y, Zhang T. PlantHelixSeek
learns transferable genome representations that capture conserved genome
grammar for functional interpretation across plant species. Molecular Plant,
2026. Manuscript MOLECULAR-PLANT-D-26-00999 (DOI to be assigned).
